# Overview

The **EC5 Star Transports website** is a modern logistics and transportation company website designed to provide information about services, enable customer inquiries, and deliver a smooth and responsive user experience.

The project focuses on performance, modern UI design, and engaging animations while maintaining a clean and scalable React architecture.

The site is built using **React and Vite** and deployed globally using **Vercel**.

# Features

- Fully responsive design for desktop, tablet, and mobile
- Smooth page animations powered by GSAP
- Client-side routing with React Router
- Contact form integration using Resend
- Fast build and development environment using Vite
- Clean and modular React component architecture
- Optimized for performance and scalability
